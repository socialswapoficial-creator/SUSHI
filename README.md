# Japan — restaurante de sushi

Site responsivo em HTML, CSS e JavaScript, com cardápio, vídeos, animações e links para WhatsApp.

## Executar

Abra `index.html` ou sirva esta pasta com um servidor estático. O projeto não exige instalação nem build.

## Publicar na Vercel

Importe o repositório, selecione **Other**, deixe o comando de build vazio e use a raiz (`.`) como diretório de saída.

## Configurar pedidos

Em `script.js`, preencha `restaurantWhatsApp` com o número do restaurante, incluindo país e DDD, apenas com dígitos. Enquanto estiver vazio, o WhatsApp abre a seleção de contatos com a mensagem pronta.

Os preços, composições e fotografias estão identificados como ilustrativos. Endereço e horários ainda precisam ser confirmados. O bloqueio de indexação foi preservado nesta versão em revisão.
